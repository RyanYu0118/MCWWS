# 建造构图参考（改编自 minecraft-builder-skill）

仅作设计提示；落地仍走 BuildBridge + 项目红线规则。

## 玻璃幕墙高层节奏

- 壳：砖 / 混凝土主墙
- 竖向玻璃节奏：约每 2 格一列（薄可用 `glass_pane`）
- 水平腰线：约每 4 格高恢复一圈壳材
- 屋顶：强调色 + 铁栏 / 天线 / 点光源，避免齐平切顶

## 真实感街区

1. 高低错落（矮商铺旁可有塔楼）
2. 巷弄：绿陶罐垃圾桶、铁栏管道、铁栏+锁链逃生梯
3. 临街：玻璃橱窗、彩色雨棚（羊毛）、门口灯笼
4. 街道家具：橡木楼梯长椅、炼药锅垃圾桶、红混凝土消防栓感小品
5. 停车：黑混凝土 + 白线；车用彩色混凝土+玻璃顶即可
6. 先留缝再填楼——负空间优先

## 立面像素字朝向

从外侧看墙：

| 墙面 | 观众视线 | 字序 |
| --- | --- | --- |
| 南墙（看向 +Z） | 自北向南看 | X 向右增，字序通常正常 |
| 北墙（看向 −Z） | 自南向北看 | 易左右反，需反序/反形 |
| 西墙 | 自东向西看 | Z 向右增，通常正常 |
| 东墙 | 自西向东看 | 易左右反 |

北墙、东墙外侧字：先反字序，必要时再反单个字形。
